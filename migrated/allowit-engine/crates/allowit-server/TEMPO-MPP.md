# Tempo runtime reference

[Execution authority](docs/execution-authority.md) is the canonical guide to shared SDK execution, server enforcement and wallet authority.
Provider protocols use common transport and journal facilities. Upstream providers retain their fulfillment coordination.

The [immutable runtime reference](https://github.com/allowit-hq/allowit-engine/blob/1956406e2e37b10bae92163b60875916f4b0789c/engine/server/TEMPO-MPP.md) preserves this earlier protocol's configuration and source bindings.
Use it to interpret those source records rather than as another current service architecture.
