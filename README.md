# Allowit on Tempo

This repository is reserved for the Tempo rail of [Allowit](https://allowit.xyz): the contracts and the rail
library that put an agent's stablecoin payments on [Tempo](https://tempo.xyz) under its owner's policy.

It holds no code now. The earlier vault, its Rust crates and its scripts are in the Git history, last at commit
[`0b36ceb`](https://github.com/allowit-hq/allowit-contracts-tempo/tree/0b36cebd995c1a4c906cc37c4e8b5161ea4212de).
That code is not maintained. The repository records no Mainnet deployment of it.
